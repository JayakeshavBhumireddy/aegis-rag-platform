# auth-service

Validates caller identity before assistant orchestration.

Responsibilities:

- authenticate caller tokens
- return an authenticated principal
- fail closed when identity cannot be established
- support a local development token format that can be replaced by OIDC/JWT

## Local API Skeleton

Endpoints:

- `GET /health/live`
- `GET /health/ready`
- `POST /v1/auth/validate`

The local implementation uses HMAC-signed dev tokens generated by
`auth_service.local_tokens.create_local_dev_token`.
